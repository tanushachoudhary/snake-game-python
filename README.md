# 🐍 Snake Game in Python

A classic Snake game built with Python using the Pygame library. Eat the food, grow the snake, and try not to hit the walls or yourself!

![433684210-3ff7a9ba-6d8c-4f17-a60b-03efc6a9917b](https://github.com/user-attachments/assets/8c16ebe9-3335-47cf-bdb7-816bdc9181a6)

## 🛠️ Features

- Classic snake movement and growth
- Score tracking
- Game over detection
- Restart option

## 🧰 Requirements

Make sure you have Python and the required libraries installed:

```bash
python3 --version
pip install pygame
```

## 🚀 How to Run

1. Clone this repository or download the `snake_game.py` file.
2. Run the game:

```bash
python snake_game.py
```

## 🎮 Controls

- **Arrow Keys** – Move the snake (Up, Down, Left, Right)
- **ESC** – Quit the game

## 🧠 Game Rules

- The snake moves continuously in the last direction pressed.
- Eating food increases your length and score.
- Colliding with walls or yourself ends the game.
